# Методы ускорения нейросетевых моделей на CIFAR-10

Практическая работа по дисциплине «Технологии анализа данных». Сравниваем дистилляцию знаний, структурированный прунинг и 8-битное квантование на задаче классификации изображений. Для каждой модели измеряем точность, размер файла весов и время инференса.

## Данные и модели

CIFAR-10 содержит цветные изображения размером 32×32 из 10 классов. Официальную обучающую выборку делим с фиксированным `seed=42` на 45 000 изображений для обучения и 5 000 для валидации. На обучении применяем случайную обрезку и горизонтальное отражение. Официальные 10 000 тестовых изображений используем для итоговой оценки. На валидации и тесте применяем только преобразование в тензор и нормализацию.

Учитель и студент используют три блока `Conv -> BatchNorm -> ReLU -> MaxPool`, глобальное усреднение и линейный классификатор на 10 классов. У учителя ширина блоков 32, 64 и 128 каналов, у студента — 16, 32 и 64.

## Порядок запуска

Понадобятся **Python 3.12** и **uv**. Все команды выполняются из папки с `pyproject.toml`. PyTorch и torchvision устанавливаются в локальное окружение из версий, зафиксированных в `uv.lock`. Для эксперимента используется CPU.

```powershell
uv sync --locked
uv run --locked python -m cifar10.download_data
```

Датасет скачивается и распаковывается в `data/`. При повторном запуске используются существующие файлы.

| Шаг | Команда | Результат в `checkpoints/` |
|---|---|---|
| 1. Обучить учителя с подбором скорости обучения | `uv run --locked python -m cifar10.tune_teacher` | `teacher_tuned.pt` |
| 2. Обучить базового студента по меткам | `uv run --locked python -m cifar10.train_student` | `student_baseline.pt` |
| 3. Обучить студента с дистилляцией | `uv run --locked python -m cifar10.train_student_distilled` | `student_distilled.pt` |
| 4. Выполнить однократный прунинг и дообучение | `uv run --locked python -m cifar10.train_student_pruned` | `student_pruned.pt` |
| 5. Выполнить итеративный прунинг и дообучение | `uv run --locked python -m cifar10.train_student_pruned_iterative` | `student_pruned_iterative.pt` |
| 6. Провести посттренировочное квантование (PTQ) | `uv run --locked python -m cifar10.evaluate_ptq` | `student_ptq.pt` |
| 7. Провести квантование с дообучением (QAT) | `uv run --locked python -m cifar10.train_student_qat` | `student_qat.pt` |
| 8. Сравнить модели | `uv run --locked python -m cifar10.compare_models` | Таблица в терминале |

Для пробного запуска учителя на одну эпоху есть отдельная команда `uv run --locked python -m cifar10.train_teacher --epochs 1`. Она сохраняет `teacher.pt`. Для дистилляции используется `teacher_tuned.pt` из шага 1. Если все семь чекпоинтов и датасет уже на месте, можно сразу запустить сравнение. Повторный запуск шага сохраняет результат под тем же именем.

## Как устроены эксперименты

- **Учитель.** Для Adam сравниваем `lr` 0.0003, 0.001 и 0.003 по 10 эпох. Сохраняем веса эпохи с наибольшей точностью на валидации. В проведённом эксперименте лучший результат - 74,14% на 9-й эпохе при `lr=0.003`.
- **Дистилляция.** Оба студента обучаются 10 эпох при `lr=0.003` с одинаковой начальной инициализацией. Для дистилляции к ошибке по меткам добавляем KL-дивергенцию между смягчёнными распределениями студента и замороженного учителя. Температура равна 3, коэффициент при масштабированном слагаемом учителя - 0,5.
- **Прунинг.** Начинаем с весов студента с дистилляцией. Суммируем абсолютные значения весов каждого фильтра и физически удаляем фильтры с наименьшей L1-нормой вместе со связанными каналами. В однократном варианте удаляем 25% фильтров каждого блока за один шаг и дообучаем три эпохи. В итеративном варианте уменьшаем ширину за три раунда и дообучаем одну эпоху после каждого. Обе модели приходят к ширине 12, 24 и 48 каналов.
- **Квантование.** PTQ и QAT начинают с одной однократно прореженной FP32-модели. PTQ калибрует диапазоны активаций на 1 024 обучающих изображениях без аугментаций. QAT имитирует 8-битное округление во время трёх эпох дообучения. После каждой эпохи на валидации оценивается уже конвертированная INT8-модель.

## Итоговые результаты

Точность измерена на официальном тесте CIFAR-10. Размер - объем файла чекпоинта. Задержка - медиана 200 прямых проходов для одного изображения на CPU с одним потоком после 30 прогревочных проходов. Для INT8 использован oneDNN. Загрузка чекпоинта и подготовка изображения выполнялись за пределами замера. Задержка может меняться между запусками и на другом оборудовании.

| Модель | Точность на тесте | Размер, КиБ | Задержка, мс |
|---|---:|---:|---:|
| Учитель FP32 | 72,80% | 378,35 | 0,483 |
| Базовый студент FP32 | 67,81% | 102,41 | 0,215 |
| Студент с дистилляцией FP32 | 67,89% | 102,41 | 0,215 |
| Однократный прунинг FP32 | 66,72% | 61,66 | 0,171 |
| Итеративный прунинг FP32 | 64,91% | 61,66 | 0,171 |
| PTQ INT8 | 66,59% | 23,83 | 0,218 |
| QAT INT8 | 67,27% | 23,83 | 0,218 |

Дистилляция дала прирост 0,08 п. п. на тесте. Однократный прунинг сократил задержку студента с 0,215 до 0,171 мс при потере 1,17 п. п. точности. В заданном расписании он сохранил на 1,81 п. п. больше точности, чем итеративный. Квантование уменьшило файл прореженной модели примерно в 2,59 раза, а измеренная задержка выросла до 0,218 мс. QAT сохранил на 0,68 п. п. больше точности, чем PTQ при одинаковом размере файла.
